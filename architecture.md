# Local Invoicing System Architecture

## Technology Stack

- **Database:** Fireproof
- **Frontend:** React
- **Build Tool:** Vite
- **UI Components:** Shadcn

## Data Model

- **Customers:** Contact information
- **Invoices:** Header details, status, customer link
- **InvoiceItems:** Line item specifics

## System Architecture

- Local-first, browser-based application
- Reactive data management
- Direct database interaction
- Decoupled UI and business logic

## Key Capabilities

- Create customers
- Generate invoices
- Modify invoices
- Delete invoices
- Print invoices
